# Python Calculator

This is a beginner-friendly calculator project built using Python. The project allows the user to enter two numbers and select an arithmetic operator to perform a calculation.

The calculator currently supports addition (`+`), subtraction (`-`), multiplication (`*`), division (`/`), and other basic arithmetic operators added during development.

The main purpose of this project is to practice Python programming concepts such as:

* Functions using `def`
* Function parameters
* `input()` for taking user input
* Variables
* `if` and `elif` conditional statements
* Arithmetic operators
* `return` statements
* Calling functions
* Storing and displaying results

This project is part of my journey to learn Python through small practical projects. Future improvements may include a graphical user interface (GUI) using Tkinter and additional calculator features.
